AIC354 Machine Learning Fundamentals — Assignment 2
Titanic Passenger Survival Prediction System

Files included:
- Titanic_Passenger_Survival_Recommended.ipynb : main Jupyter/Colab notebook
- sample-data.csv                         : 100-row simplified Titanic dataset
- svc_trained_model.pkl                   : trained SVC model
- app.py                                  : Streamlit deployment app
- requirements.txt                        : deployment dependencies
- sample-data-encoded.csv                : encoded dataset generated by notebook
- training-data-encoded.csv              : 80% training split
- testing-data-encoded.csv               : 20% testing split
- model-predictions.csv                  : test predictions

Deployment:
Upload app.py, svc_trained_model.pkl and requirements.txt to a GitHub repository,
then deploy the repository/app.py using Streamlit Community Cloud.
